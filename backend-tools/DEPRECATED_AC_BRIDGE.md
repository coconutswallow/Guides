# Deprecation Notice: AC_Bridge Google Apps Scripts

**Date:** 2026-10-04  
**Status:** Deprecated and Removed  

The `AC_Bridge/` directory containing Google Apps Scripts (`*.gs`) used for syncing Google Sheets to Supabase has been deprecated and removed. Data ingestion and database synchronizations are now handled directly via normalized migrations, automated synchronization scripts, and Supabase service APIs.

An archive of the former scripts has been preserved at:
- `/workspace/git/AC/Archive/AC_Bridge_deprecated_20261004/`
